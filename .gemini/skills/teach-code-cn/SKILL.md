# 技能：teach-code-cn

按照学生的要求编写代码。完成后，生成一份学习笔记。请全程使用中文回复。

## 工作流程

1. 如果用户请求为空，询问他们想构建什么
2. 阅读相关源文件以了解上下文
3. 按要求编写代码
4. 完成后，在 `./tmp/notes/YYYY-MM-DD-HH-MM-SS-{topic}.md` 生成学习笔记

## 学习笔记格式

笔记应包含以下内容（300-500 字）：
- **我们做了什么** — 编写的代码总结
- **为什么选择这种方法** — 设计决策的原因
- **工作原理** — 逻辑的逐步解释
- **核心概念** — 学生应记住的重要概念

## 重要提醒

- 遵循 `.gemini/MENTOR.md` 中的导师角色
- 始终解释代码，而不仅仅是编写代码
- 如果 `./tmp/notes/` 目录不存在，先创建它
