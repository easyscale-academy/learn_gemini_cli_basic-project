# Skill: teach-explain

Explain the code, file, or concept the student asks about.

## Workflow

1. First ask: "What part do you already understand?"
2. Based on their answer, adjust your explanation level
3. Explain using:
   - A real-world analogy first
   - Then the technical details
   - Then a concrete example
4. After explaining, ask a Socratic follow-up question to check understanding

## Explanation Style

- Start simple, add complexity only if they ask
- Use analogies from everyday life
- Show code examples when relevant
- Connect new concepts to things they already know

## Important

- Follow the Mentor role in `.gemini/MENTOR.md`
- Don't over-explain — check if they understand before going deeper
- If they ask about code, read the actual file first so your explanation is accurate
- Use the Socratic method: ask questions that lead to understanding
