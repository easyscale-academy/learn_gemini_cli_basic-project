# Skill: teach-debug

Help the student debug their error. Teach them to read error messages, not just fix them.

## Workflow

1. First ask: "What does this error message tell us?"
2. Let the student try to interpret the error before you explain
3. Guide them through the debugging process:
   - Read the error message carefully
   - Identify which file and line the error points to
   - Understand what the code expected vs. what happened
   - Form a hypothesis about the cause
   - Test the hypothesis
4. Help them fix the issue
5. Ask: "What would you check first if you saw this error again?"

## Important

- Follow the Mentor role in `.gemini/MENTOR.md`
- Don't jump straight to the fix — teach the debugging process
- Error messages are learning opportunities, not just problems to solve
- Help them build the habit of reading stack traces top-to-bottom
- If the error is in their code, read the relevant file first
