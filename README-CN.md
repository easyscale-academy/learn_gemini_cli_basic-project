## 什么是 Claude Code？

一句话：**Claude Code 是一个住在你电脑 Terminal（命令行）里的 AI 助手，它能像一个真人一样，自己探索、自己动手、自己解决问题。**

官方的说法是：它是一个 "agentic coding tool"——一个具有自主行动能力的编程工具。

但这个定义太窄了。

虽然它叫 "Code"，虽然它在程序员群体里最火，但 **Claude Code 的能力远不止写代码**。稍加配置，它可以：

- 操作浏览器，帮你自动完成网页上的任务
- 访问数据库，做数据分析和可视化报表
- 下载 YouTube 视频，提取字幕，做内容分析
- 读取你的文件，整理笔记，生成报告
- 甚至——如果它发现自己缺少某个工具，它会**现场写一个工具出来**，然后用这个工具完成任务

**它的能力边界，取决于你给它什么权限，而不是它本身有什么限制。**

Anthropic 公司内部（就是做 Claude 的那家公司）已经在用 Claude Code 做 deep research（深度调研）、video creation（视频制作）、note-taking（笔记整理）等各种非编程工作。

## 什么是 Agent？为什么它和普通 AI 聊天完全不同？

要理解 Claude Code 的厉害之处，你得先理解一个概念：**Agent（智能体）**。

### 普通的 AI 聊天是什么样的？

想象你在 Claude AI 的网页版里聊天。你问一个问题，它回答一个答案。就像去柜台办事：

- **你**负责提供所有背景信息（"我要办什么业务"、"我的情况是什么"）
- **AI** 负责处理你给的信息，然后给你一个回复
- 一来一回，交易完成

如果你忘了说某个重要信息，它不会自己去找。如果回答得不对，你得自己发现问题，然后重新问。

**这是一次性买卖。** AI 像一个很聪明的客服，但它只能坐在那里等你问。

### Agent 是什么样的？

Agent 完全不同。它更像你雇了一个**实习生**或者**助理**。

你跟它说："帮我把这个项目的代码整理一下，看看有没有 bug。"

然后它开始**自己行动**：

1. **探索环境**："让我先看看这个文件夹里有什么..." 它自己打开文件夹，浏览文件列表
2. **理解上下文**："这个文件好像是主程序，先看看前几行..." 它不会一口气读完所有内容，而是像人一样，先快速浏览，找重点
3. **制定计划**："OK，我理解了，这是一个 Python 项目，用了 Flask 框架，我应该先检查..."
4. **尝试执行**：它开始运行代码、检查输出
5. **遇到问题**：代码报错了
6. **自己 debug**：它看报错信息，分析原因，修改代码，再跑一次
7. **循环往复**：直到任务完成

**整个过程，你只说了一句话。剩下的，它自己搞定。**

这就是 Agent 和普通 AI 聊天的本质区别：

| 普通 AI 聊天 | Agent |
| --- | --- |
| 你提供所有信息 | 它自己去找信息 |
| 一问一答 | 持续行动直到完成 |
| 出错了你来发现 | 出错了它自己 debug |
| 被动等待指令 | 主动规划和执行 |

## Claude Code 为什么这么厉害？

现在你理解了 Agent 的概念，再来看 Claude Code 就清楚了。

**Claude Code 就是把 Claude 这个强大的 AI 大脑，装进了一个能自主行动的 Agent 框架里。**

它跟你在 Claude AI 网页版聊天时用的是同一个 AI（同样的 Claude Sonnet 或 Opus 模型），但它多了关键的能力：

### 1. 自主探索文件系统

在 Claude AI 网页版里，你要一个一个上传文件，维护知识库。

在 Claude Code 里，你只要告诉它"这个文件夹里有我的项目"，它就会**自己去翻**。它会看文件名、读文件内容、理解项目结构——就像一个新来的同事熟悉项目一样。

### 2. 运行代码和命令

Claude Code 可以直接在你的电脑上执行代码。写完代码，跑一下，看结果，改一改，再跑——这个循环它可以自己完成。

### 3. Debug 能力

代码报错了？Claude Code 会读错误信息，分析原因，尝试修复，再运行验证。很多时候，它能自己把问题解决掉，你根本不需要介入。

### 4. 无限扩展

通过 MCP（Model Context Protocol），你可以给 Claude Code 接上各种外部工具：

- 连接 Google Drive，让它读你的文档
- 连接 Jira，让它帮你管理任务
- 连接数据库，让它做数据分析
- 连接任何有 API 的服务

**厉害的人用 Claude Code，能把自己的能力放大十倍甚至一百倍。** 但即使是初学者，它也是一个极好的导师——因为它会一步一步地探索、尝试、解释，你可以跟着它学习。

## 为什么我们以前没用过？

说实话，Claude Code 之前一直存在，但我们没有在课程中使用，原因很简单：**我们以前没有足够的使用额度。**

OfferForge 一直用的是 Claude Team Plan（团队计划）。但在 2026 年 1 月 16 日之前，Team Plan 的用户是没有 Claude Code 访问权限的。

现在情况变了。**从 1 月 16 日起，Anthropic 给所有 Team Plan 用户开放了 Claude Code 的访问权限。**

这意味着什么呢？

如果你是个人用户，想用 Claude Code，通常有两个选择：

- **$20/月的 Pro Plan**：但限制很大，大概每 5 小时只能发 9 条消息。稍微认真干点活，很快就用完了。
- **$100/月的 Max Plan**：额度够用，但对学生来说太贵了。

而我们 Team Plan 的企业用户，**额度是个人 Pro Plan 的三倍多**，足够你在学习和项目中正常使用。

**所以，现在是时候把这个强大的工具介绍给你了。**
