# Claude Code 基础操作（三）：用截图让 AI 理解界面

[Extension: com.atlassian.confluence.macro.core/toc]

## 为什么要学这个？

你遇到一个报错界面，想问 AI 怎么解决。你可以尝试用文字描述："就是那个红色的框，里面写了一堆英文，好像是什么 error..."

但这样描述既费劲又不准确。**更好的方法：直接截图给 AI 看。**

一图胜千言。Claude Code 可以"看懂"图片，包括：

- 错误信息截图
- UI 界面截图
- 代码截图
- 流程图、架构图

学会用截图和 AI 沟通，能大大提高问问题的效率。

---

## 操作步骤

### 第一步：截图并保存到本地

**在 Mac 上：**

- `` Cmd + Shift + 4 `` — 选择区域截图
- 截图会自动保存到桌面（或你设置的默认位置）

**在 Windows 上：**

- `` Win + Shift + S `` — 选择区域截图
- 截图会保存到剪贴板，你需要粘贴到文件中保存

**在 Codespace 中（浏览器里）：**

- 使用操作系统自带的截图工具
- 把截图保存到你能找到的地方

### 第二步：把截图文件放到 Codespace 中

如果你在浏览器中使用 Codespace，需要把截图上传进去：

1. 在 Codespace 左侧的 Explorer 面板中，找到你想放截图的文件夹
2. **右键点击文件夹 → 选择 "Upload..."**
3. 选择你刚才保存的截图文件
4. 等待上传完成

### 第三步：复制截图的绝对路径

上传完成后，截图会出现在文件列表中：

1. **右键点击截图文件**
2. **选择 "Copy Path"**（和复制代码文件路径一样）

你会得到类似这样的路径：

```
/workspaces/my-project/screenshots/error-message.png
```

### 第四步：把路径发给 AI

在 Claude Code 输入框中这样说：

```
请看一下这个截图，告诉我这个错误是什么意思，怎么解决：
/workspaces/my-project/screenshots/error-message.png
```

AI 会"看"这张图片，然后回答你的问题。

## 小练习：动手试一试

**目标：** 让 Claude Code 帮你解读一个界面截图

**步骤：**

1. **截图：** 对你当前的 Codespace 界面截一张图（随便截什么都行，比如左侧的文件列表）
2. **上传：** 在 Codespace 的 Explorer 面板中，右键某个文件夹 → Upload，上传你的截图
3. **复制路径：** 右键点击上传的截图文件 → Copy Path
4. **问 AI：** 在 Claude Code 中输入：
```
请看一下这个截图，告诉我截图里显示的是什么界面：[粘贴你复制的路径]
```
5. 按 Enter 发送

**预期结果：** AI 会描述截图中的内容，比如"这是 VS Code 的文件浏览器面板，显示了项目的文件结构..."

---

## 截图的最佳实践

**截图要清晰：**

- 确保文字清晰可读
- 不要截太小，重要信息要能看清

**截图要聚焦：**

- 只截相关的部分，不要截整个屏幕
- 错误信息就只截错误框，不要截整个 IDE

**命名有意义：**

- 给截图起一个描述性的名字，如 `` error-npm-install.png ``
- 避免使用默认的 `` Screenshot 2024-01-15 at 10.30.45.png `` 这种名字

## 小结

- 截图 → 上传到 Codespace → 复制路径 → 发给 AI
- AI 可以"看懂"图片，包括错误信息、UI 界面、代码等
- 一图胜千言，比文字描述更准确高效
