## 核心概念

### 什么是 Gemini CLI？

一句话：**Gemini CLI 是一个住在你电脑 Terminal（命令行）里的 AI 助手，它能像一个真人一样，自己探索、自己动手、自己解决问题。**

Google 官方的说法是：它是一个 "open-source AI agent"（开源 AI 智能体）——一个具有自主行动能力的 AI 工具，直接跑在你的终端里。

但这个描述太含蓄了。

虽然它在程序员群体里最火，但 **Gemini CLI 的能力远不止写代码**。稍加配置，它可以：

- 读取你的文件，整理笔记，生成报告
- 在你的电脑上直接执行 shell command（命令）和脚本
- 用 Google Search 搜索最新的网络信息
- 通过 MCP（Model Context Protocol）连接各种外部服务
- 甚至——如果它发现自己缺少某个工具，它会**现场写一个工具出来**，然后用这个工具完成任务

**它的能力边界，取决于你给它什么权限，而不是它本身有什么限制。**

### 什么是 Agent？为什么它和普通 AI 聊天完全不同？

要理解 Gemini CLI 的厉害之处，你得先理解一个概念：**Agent（智能体）**。

**普通的 AI 聊天是什么样的？**

想象你在 Gemini 的网页版（gemini.google.com）里聊天。你问一个问题，它回答一个答案。就像去柜台办事：

- **你**负责提供所有背景信息（"我要办什么业务"、"我的情况是什么"）
- **AI** 负责处理你给的信息，然后给你一个回复
- 一来一回，交易完成

如果你忘了说某个重要信息，它不会自己去找。如果回答得不对，你得自己发现问题，然后重新问。

**这是一次性买卖。** AI 像一个很聪明的客服，但它只能坐在那里等你问。

**Agent 是什么样的？**

Agent 完全不同。它更像你雇了一个**实习生**或者**助理**。

你跟它说："帮我把这个项目的代码整理一下，看看有没有 bug。"

然后它开始**自己行动**：

1. **探索环境**："让我先看看这个文件夹里有什么..." 它自己打开文件夹，浏览文件列表
2. **理解上下文**："这个文件好像是主程序，先看看前几行..." 它不会一口气读完所有内容，而是像人一样，先快速浏览，找重点
3. **制定计划**："OK，我理解了，这是一个 Python 项目，用了 Flask 框架，我应该先检查..."
4. **尝试执行**：它开始运行代码、检查输出
5. **遇到问题**：代码报错了
6. **自己 debug**：它看报错信息，分析原因，修改代码，再跑一次
7. **循环往复**：直到任务完成

**整个过程，你只说了一句话。剩下的，它自己搞定。**

这就是所谓的 **ReAct loop**（Reason and Act，推理并行动）—— agent 先想该做什么，然后动手做，观察结果，再重复。这是区分 agent 和 chatbot 的根本模式。

**核心区别：**

- **普通 AI 聊天：** 你提供所有信息。**Agent：** 它自己去找信息。
- **普通 AI 聊天：** 一问一答。**Agent：** 持续行动直到完成。
- **普通 AI 聊天：** 出错了你来发现。**Agent：** 出错了它自己 debug。
- **普通 AI 聊天：** 被动等待指令。**Agent：** 主动规划和执行。

### Gemini CLI 为什么这么厉害？

现在你理解了 Agent 的概念，再来看 Gemini CLI 就清楚了。

**Gemini CLI 就是把 Google 强大的 Gemini AI 大脑，装进了一个能自主行动的 Agent 框架里。**

它跟你在 Gemini 网页版聊天时用的是同一个 AI（Gemini 2.5 Pro 模型），但它多了关键的能力：

**1. 自主探索文件系统**

在 Gemini 网页版里，你要手动上传文件或者粘贴代码。

在 Gemini CLI 里，你只要告诉它"这个文件夹里有我的项目"，它就会**自己去翻**。它会看文件名、读文件内容、理解项目结构——就像一个新来的同事熟悉项目一样。

**2. 运行代码和命令**

Gemini CLI 可以直接在你的电脑上执行代码。写完代码，跑一下，看结果，改一改，再跑——这个循环它可以自己完成。

**3. Debug 能力**

代码报错了？Gemini CLI 会读错误信息，分析原因，尝试修复，再运行验证。很多时候，它能自己把问题解决掉，你根本不需要介入。

**4. 内置 Google Search**

不像很多 coding agent，Gemini CLI 天生就内置了 Google Search。它能查文档、搜索错误信息的解决方案、用最新的网络信息来验证自己的回答。这是 Google 做 AI 工具的独特优势。

**5. 通过 MCP 无限扩展**

通过 MCP（Model Context Protocol），你可以给 Gemini CLI 接上各种外部工具和服务——数据库、项目管理工具、API 等等。

**厉害的人用 Gemini CLI，能把自己的能力放大十倍甚至一百倍。** 但即使是初学者，它也是一个极好的导师——因为它会一步一步地探索、尝试、解释，你可以跟着它学习。

### 为什么是 Gemini CLI？为什么是现在？

这里有一个让人激动的事情：**Gemini CLI 完全免费，而且开源。**

Google 把 Gemini CLI 作为开源项目发布，你只需要一个 Google 账号就能用。你可以免费使用 Gemini 2.5 Pro——这是目前最强大的 AI 模型之一。免费额度非常慷慨，每分钟 60 个请求，每天 1,000 个请求。

对比其他 AI coding agent 动不动就要 $20/月甚至更多的订阅费，**Gemini CLI 直接把成本门槛降到了零**。

这意味着：

- **不需要付费订阅** —— 有个 Google 账号就行
- **免费额度完全够用** —— 日常学习和项目开发足够了
- **开源** —— 你能看到它的源代码，可以贡献代码，也可以自己改
- **Google 背书** —— 背后是 Gemini 模型的全部实力

**现在是开始使用 AI coding agent 的最佳时机。**

## 小结：我们学到了什么？

来回顾一下关键要点：

- **Gemini CLI 是什么？** 一个住在 Terminal 里的 AI Agent，能自主探索、行动、解决问题
- **它只能写代码吗？** 不，它能做任何事——写代码只是它最出名的应用场景
- **Agent 和普通 AI 聊天的区别？** 普通 AI 被动等你问；Agent 主动行动直到任务完成
- **什么是 ReAct loop？** Agent 的核心模式：推理 → 行动 → 观察 → 重复
- **为什么它这么厉害？** 因为它能自己探索文件、运行代码、debug、搜索网络、通过 MCP 扩展
- **为什么是现在？** 因为它免费、开源、由 Google 最强大的 AI 模型驱动

## 导师寄语

**为什么这节课很重要：**

我知道这节课可能感觉有点特别——没有代码要写，没有命令要跑。但我想让你明白一件事：「Agent vs. Chatbot」这个概念，是当下 AI 工具领域最重要的一个理念。

大多数人还停留在 chatbot 的思维模式里。他们从 ChatGPT 里复制代码，粘贴到编辑器里，跑一下，报错了，再把错误信息复制回 ChatGPT，如此反复。这种工作方式又累又低效。

Agent 把这一切翻转过来了。你描述你想要什么，agent 来处理整个循环——读文件、写代码、运行、debug、迭代。你的角色从「做事的人」变成了「指导的人」。这是人类和 AI 协作方式的根本性变革。

**关键洞察：**

- 懂 agent 的人和不懂的人之间的差距正在飞速拉大。这不是关于编程水平的高低——而是关于你是否知道这些工具的存在，以及如何使用它们
- Gemini CLI 免费且开源，意味着没有任何理由不去尝试。入门门槛从来没有这么低过
- 不要把它想成「一个编程工具」。把它想成「一个能力很强的助理，碰巧在终端里运行」。这个思维模型会让你受益更多
