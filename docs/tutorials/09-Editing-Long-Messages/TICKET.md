# Learn Gemini CLI Basic 09 - Learn to Edit Long Messages in Gemini CLI

## Objective

Learn how to compose and edit long messages efficiently using a markdown file instead of typing directly in the chat input box.

Read the tutorial: [Editing Long Messages](https://github.com/easyscale-academy/learn_gemini_cli_basic-project/tree/09-Editing-Long-Messages/)

## Actionable Items

1. Read the tutorial in `README.md`
2. Open `.gemini/gemini-messages-example.md` in your editor
3. Copy the sample message at the bottom and paste it into Gemini CLI
4. Observe how Gemini responds to your message
5. Try adding your own message to the file and sending it
6. Try using Ctrl+X to open your editor for a longer message
7. Leave a comment on this ticket to let your mentor know you've completed it

**Estimated time:** 5-10 minutes
