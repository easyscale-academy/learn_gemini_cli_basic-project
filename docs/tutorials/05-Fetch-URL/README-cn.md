# Gemini CLI 基础操作：用 URL 让 AI 读取网页

> 学会把 URL 丢给 Gemini CLI，让 AI 帮你读取、总结、解释网页内容。

## 概述

你在网上找到一篇技术文档，想让 AI 帮你解读。传统做法是：复制全文 → 粘贴给 AI → 发现太长了粘贴不完 → 放弃。

更聪明的做法：直接把链接丢给 AI，让它自己去读。Gemini CLI 可以直接访问和读取网页内容——你只要把 URL 粘贴进去，它就会读取内容并回答你的问题。比复制粘贴高效 10 倍。

## 学习目标

你以后会经常遇到这种情况：找到一篇文档、教程、GitHub README，需要快速搞明白。也许是一个没用过的库，也许是同事的项目页面。与其花 20 分钟反复阅读，不如把 URL 丢给 Gemini CLI，几秒钟就能拿到总结。这个技能让 AI 变成你的私人研究助手。

学完这节课，你将能够：

1. 把 URL 丢给 Gemini CLI，让它读取网页内容
2. 用不同的提示方式让 AI 总结、解释、或从网页中提取特定信息
3. 了解哪些网页 AI 能读，哪些不能

- 打开了这个项目的 GitHub Codespace

## 核心概念

### URL 读取是怎么工作的

当你在 Gemini CLI 中粘贴一个 URL 时，AI 会做三件事：

1. **访问网页** — 它向 URL 发送请求，就像浏览器一样
2. **读取内容** — 它提取页面中的文字
3. **回答你的问题** — 它基于页面内容来回应你的提问

你不需要任何特殊语法。直接把 URL 和你的问题一起粘贴到提示中就行。

### 基本模式

```
[你的问题] [URL]
```

或者反过来：

```
[URL] [你的问题]
```

两种都行。AI 能分辨哪个是 URL、哪个是你的问题。

### AI 能读和不能读的网页

**能读的网页：**
- 公开访问的页面（不需要登录的）
- 技术文档、博客文章、GitHub README、新闻报道
- API 文档、教程、Wiki 页面

**不能读的网页：**
- 需要登录才能看的页面（比如你的 Gmail 邮箱、私有 Slack 频道）
- 付费内容、会员专属内容
- 某些阻止自动访问的网站

如果 AI 说"无法访问这个页面"，通常就是遇到了上述限制。这时候你需要手动复制页面内容给 AI。

## 练习

### 练习 1：读取一个网页

**目标：** 让 Gemini CLI 读取并总结一个公开网页。

**步骤：**

1. 在终端中打开 Gemini CLI（输入 `gemini` 然后按 Enter）
2. 输入以下提示并按 Enter：

```
Read this page and give me the key takeaways: https://github.com/google-gemini/gemini-cli
```

3. 观察 Gemini 如何访问页面并为你总结

**你会看到：**

Gemini 访问了 URL，读完页面内容，然后给你一个总结。你不需要打开浏览器、读完整个页面、或复制任何内容。

> **关键要点：** 直接把 URL 粘贴到提示中，AI 就会帮你读取页面。不需要任何特殊语法。

---

### 练习 2：针对网页问特定问题

**目标：** 用 URL 向 AI 问一个有针对性的问题。

**步骤：**

1. 在 Gemini CLI 中，输入：

```
https://docs.github.com/en/codespaces/overview
What exactly is a GitHub Codespace? Explain it in plain English, in 3 sentences.
```

2. 按 Enter，看 Gemini 如何基于页面内容回答

**你会看到：**

Gemini 不会给你泛泛的答案，而是基于页面实际内容来解释。这比没有来源地问一个笼统问题要准确得多。

> **关键要点：** 把 URL 和具体问题结合起来，Gemini 就变成了一个基于实际来源回答的研究助手，而不只是依赖训练数据。

---

### 练习 3：提取具体细节

**目标：** 让 Gemini 在网页中找到并提取特定信息。

**步骤：**

1. 选一个你感兴趣的公开技术文档页面（比如 Python 文档、React 文档、或任何 GitHub README）
2. 在 Gemini CLI 中输入：

```
[粘贴你选的 URL]
Does this page mention anything about installation or getting started? Walk me through the steps.
```

3. 按 Enter，看 Gemini 如何找到并呈现具体信息

**你会看到：**

Gemini 不只是总结——它能在页面中找到特定的段落和细节。这对于快速定位你需要的信息非常有用，不用读完整篇文档。

> **关键要点：** 你可以针对网页的任何部分提问。AI 就像一个真正能理解内容的搜索引擎。

---

## 回顾：我们学到了什么？

- 把 **URL 粘贴**到 Gemini CLI 的提示中，AI 就会访问并读取页面
- 你可以让它**总结、解释、或查找**页面中的特定信息
- 适用于任何公开网页——文档、博客、GitHub 页面、文章
- 需要登录或付费的页面不行
- 比复制粘贴全文高效得多

这看起来可能只是一个方便的功能，但它其实从根本上改变了你的工作方式。以前研究一个新库，你得开一堆标签页、扫读文档、费力拼凑信息。现在你有了一个能帮你读文档、实时回答问题的 AI。这不只是更快——它改变了你学习和探索新技术的方式。

**核心洞察：**

- URL 读取让 Gemini CLI 从代码助手升级为研究搭档。每当你遇到新东西——一个库、一个框架、一个 API——你的第一步可以是：粘贴文档 URL 然后问问题。
- 文件引用（上节课的 `@`）加上 URL 读取，给了你两种强大的方式来给 AI 提供上下文：本地文件和网页。两者结合起来，能覆盖你遇到的大多数场景。

**下一步：**

养成习惯：每当你在网上读技术文档时，试着把 URL 粘贴到 Gemini CLI 中问它总结或解释。把 AI 的总结和你自己的理解对比一下——这是检验理解力和发现遗漏的好方法。
