# Feeding URLs to Gemini CLI

## Objective

Learn how to paste a URL into Gemini CLI and have it read and interpret the web page for you — ten times faster than copying and pasting the whole thing.

Read the tutorial: [Gemini CLI Basics: Getting AI to Read Web Pages for You](https://github.com/easyscale-academy/learn_gemini_cli_basic-project/tree/05-Fetch-URL/)

## Actionable Items

1. Read the tutorial (`@README.md`) to understand how URL fetching works in Gemini CLI
2. Open Gemini CLI and complete all three exercises in the tutorial
3. Work through every item in the Checklist below

**Estimated time:** 10-15 minutes

## Checklist

- [ ] **Read the tutorial** — Understand how to feed URLs to Gemini CLI, including which pages it can and can't access
- [ ] **Exercise 1: Read a web page** — Paste `https://github.com/google-gemini/gemini-cli` into Gemini CLI and get a summary of the page
- [ ] **Exercise 2: Ask a specific question** — Use a URL with a targeted question and get an answer grounded in the page's actual content
- [ ] **Exercise 3: Extract specific details** — Pick a technical docs page and ask Gemini to find specific information (like installation steps)
- [ ] **Verify the output** — Confirm that the AI read the page correctly and gave you useful, accurate responses

## Grading Rubric

- **URL fetching understanding:** Student can explain that pasting a URL into the prompt causes Gemini CLI to fetch and read the page content. They understand no special syntax is needed — just paste the URL.
- **Page summary:** Student successfully pasted a URL (e.g., Gemini CLI GitHub page) and received a content-based summary from Gemini CLI. The response should reference actual page content, not generic knowledge.
- **Targeted question:** Student combined a URL with a specific question and got an answer grounded in the page's contents (not a generic response from training data).
- **Detail extraction:** Student asked Gemini to find specific information on a page and received relevant, accurate details pulled from the page content.
- **Access limitations awareness:** Student can explain that login-required pages, paywalled content, and access-restricted sites cannot be read by the AI.
