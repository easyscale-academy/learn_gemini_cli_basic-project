# Gemini CLI 基础操作：用 @ 让 AI 读取你的文件

> 学会在 Gemini CLI 中用 `@` 符号引用文件，让 AI 读取并理解你的代码。

## 概述

用 Gemini CLI 的时候，你随时都需要让 AI 看某个特定文件——配置文件、脚本、组件。但如果你只说"帮我看看那个文件"，AI 根本不知道你说的是哪个。

Gemini CLI 用了一个简单的约定：输入 `@` 加上文件的相对路径，比如 `@README.md` 或 `@src/main.py`。就这么简单，AI 就能读到你指定的文件了。

## 学习目标

想象一下，你的项目有几十个文件。你想让 AI 帮你检查数据库配置，但项目里有三个不同文件夹的 config 文件。如果没有精确的方式指定文件，你只能反复解释"不是这个，是那个"。`@` 语法给了你一个直接、不会搞混的方式来说"读这个文件"——每次都管用。

学完这节课，你将能够：

1. 理解绝对路径和相对路径的区别
2. 用 `@` + 相对路径在 Gemini CLI 中引用文件
3. 把 `@` 引用和自然语言提示结合起来，获得有用的 AI 回答

## 前置条件

- 已安装并登录 Gemini CLI（上节课完成的）
- 打开了这个项目的 GitHub Codespace
- 基本的终端操作能力

## 最终成果

这次不需要构建什么——这是一个技能练习。你会练习引用文件让 AI 读取，这是未来所有让 AI 分析、编辑、解释代码的基础。

## 核心概念

### 绝对路径 vs. 相对路径

电脑里每个文件都有一个地址，叫做**路径（Path）**。路径分两种：

- **绝对路径（Absolute Path）** — 从系统根目录开始，比如 `/workspaces/my-project/src/main.py`。就像文件的完整门牌号，全局唯一。
- **相对路径（Relative Path）** — 从当前目录开始，比如 `src/main.py` 或 `./src/main.py`。更短，但取决于你现在在哪。

打个比方：绝对路径就像写快递地址"上海市浦东新区张江高科技园区XXX号"——无论谁看都能找到。相对路径就像说"前面路口左转"——只有知道你现在站在哪里的人才懂。

### 为什么 Gemini CLI 用相对路径

Gemini CLI 运行在你的项目文件夹里，所以它已经知道"这里"是哪里。这意味着相对路径完全够用——你不需要每次都打一长串完整地址。只要告诉它从项目根目录算起的路径就行。

比如你的项目结构是这样的：

- `README.md`
- `src/main.py`
- `src/config.json`
- `tests/test_main.py`

你可以用项目根目录开始的路径引用任何文件：`@README.md`、`@src/main.py`、`@src/config.json`。

### @ 符号：你的文件引用工具

在 Gemini CLI 中，`@` 符号就是你告诉 AI"我在指向一个文件"的方式。当 Gemini 看到你的提示中有 `@src/main.py`，它就会读取那个文件并把内容带入对话。

**语法很简单：**

```
@<文件的相对路径>
```

**实际例子：**

```
@README.md
@src/main.py
@src/components/Button.tsx
@tests/test_config.py
```

你把这些 `@` 引用直接放到自然语言提示里，Gemini 会自动处理。

### 如何在 Codespace 中获取相对路径

在 GitHub Codespace 的文件浏览器（左侧 Explorer 面板）中：

1. **找到你要的文件** — 在文件树中定位
2. **右键点击文件名** — 弹出菜单
3. **选择 "Copy Relative Path"** — 复制相对于项目根目录的路径

你会得到类似 `src/components/Button.tsx` 这样的路径。然后在输入提示时，在前面加上 `@` 就行了。

> **注意：** 菜单中还有一个 "Copy Path" 选项，那个复制的是绝对路径。在 Gemini CLI 中，你要选的是 **"Copy Relative Path"**。

## 练习

### 练习 1：读取单个文件

**目标：** 让 Gemini CLI 读取并总结项目中的一个文件。

**步骤：**

1. 在终端中打开 Gemini CLI（输入 `gemini` 然后按 Enter）
2. 输入以下提示并按 Enter：

```
Summarize what this file is about: @README.md
```

3. 观察 Gemini 如何读取文件并给你一个总结

**你会看到：**

Gemini 读取了整个文件内容，然后用简单的语言给你一个总结。你不需要复制粘贴任何内容——只靠 `@` 引用就够了。

> **关键要点：** `@` 符号把文件路径变成了文件引用。Gemini 会自动读取文件并把内容纳入对话。

---

### 练习 2：针对文件问特定问题

**目标：** 用 `@` 引用文件并问一个有针对性的问题。

**步骤：**

1. 在 Gemini CLI 中，挑一个项目里的文件（比如 `TICKET.md` 或 `CLAUDE.md`）
2. 在 Explorer 面板中右键点击，选 **Copy Relative Path**
3. 用 `@` 引用输入一个具体问题：

```
What are the checklist items in @TICKET.md?
```

4. 按 Enter，看 Gemini 如何基于文件实际内容回答

**你会看到：**

Gemini 不会瞎猜——它读取文件，然后基于里面的实际内容回答。这就是你获得精确、有据可查的回答而不是泛泛而谈的方法。

> **关键要点：** 把 `@` 引用和具体问题结合起来，你就能通过自然对话来探索你的代码库。

---

### 练习 3：引用多个文件

**目标：** 在一个提示中引用多个文件。

**步骤：**

1. 在 Gemini CLI 中，输入一个引用两个文件的提示：

```
Compare @README.md and @TICKET.md — what's the difference between these two documents?
```

2. 按 Enter，看 Gemini 如何读取两个文件并进行比较

**你会看到：**

Gemini 读取两个文件并给你一个对比。你可以在一个提示中引用任意多个文件。

> **关键要点：** 一个提示中不限于只用一个 `@` 引用。需要多少就用多少，让 Gemini 看到完整的画面。

---

### 练习 4：总结这篇教程本身

**目标：** 用 Gemini CLI 总结你正在读的这篇教程。

**步骤：**

1. 在 Gemini CLI 中，输入：

```
summarize @README.md
```

2. 按 Enter，读一下 Gemini 给你的总结

**你会看到：**

Gemini 读取了你一直在跟着学的教程文件，然后生成一个简洁的总结。这是检验你理解程度的好方法——AI 的总结和你觉得自己学到的内容一致吗？

> **关键要点：** 你可以用 `@` 引用任何文件，包括教程本身。这是快速回顾长文档的好技巧，不用从头到尾重新读一遍。

---

## 回顾：我们学到了什么？

- **相对路径**从项目根目录开始，比绝对路径短——非常适合在项目内部使用
- Gemini CLI 中的 **@ 符号**告诉 AI 去读取某个文件
- 语法是 `@<相对路径>` — 放在提示中的任何位置都行
- 在 Codespace 中用 **"Copy Relative Path"** 可以快速获取正确的路径
- 一个提示中用多个 `@` 引用可以给 AI 更全面的上下文

## 导师寄语

**为什么这个练习很重要：**

我知道这节课可能感觉太简单了——打个 `@`，粘贴个路径，搞定。但这就是我觉得它是你要学的最重要技能之一的原因：你和 AI 互动的质量，完全取决于你提供的上下文。没有上下文的 AI 只是在猜。加载了正确文件的 AI？那才是真正的搭档。

**核心洞察：**

- `@` 语法是你让 AI 回答"落地"的主要工具。没有它，AI 靠记忆和假设工作。有了它，AI 基于你的实际代码工作。
- 现在熟练掌握文件引用，后面会有巨大回报。每个高级技巧——代码审查、重构、调试——都是从把 AI 指向正确的文件开始的。

**下一步：**

试着在日常工作中使用 `@` 引用。每次你问 Gemini CLI 关于代码的问题时，带上相关的文件引用。你会发现回答变得有用得多。
