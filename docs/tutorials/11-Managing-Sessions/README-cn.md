# 管理会话

> 学习 Gemini CLI 会话的工作原理，以及如何在多个对话中管理对话历史。

## 为什么这很重要

想象一下：你已经和 Gemini CLI 对话了三十分钟，积累了大量关于项目的上下文。你解释了架构，讨论了一个棘手的 bug，眼看就要找到解决方案了。然后你的终端崩溃了，或者你需要去吃午饭。

如果没有会话管理，所有的上下文都会丢失。你得从头开始，重新解释一切。

有了会话功能，Gemini CLI 会自动保存你的对话。你可以从上次离开的地方继续——无需重新解释，不会丢失上下文。就像拥有一本记住一切的笔记本，即使合上它也不会忘记。

---

## 什么是会话？

**会话**是与 Gemini CLI 的一次对话，包括你说的所有内容和 Gemini 的所有回复。可以把它想象成笔记本中的一页：

- 每次启动 Gemini CLI，你都会得到**新的一页**（新会话）
- 你讨论的所有内容都记录在这一页上
- 退出时，这一页会自动保存
- 下次启动时，你会得到一页新的空白页——除非你选择翻回之前的某一页

---

## 理解会话持久性

关键要理解的是：**会话默认是隔离的**。每个新会话都从空白状态开始。

**会话 1：**
```
                        告诉你：我最喜欢的食物是披萨
好的！你最喜欢的食物是披萨。我记住了。

                        我最喜欢的食物是什么？
你最喜欢的食物是披萨。
（退出 Gemini CLI - 会话已保存）
```

**会话 2：**（新会话，全新开始）
```
                        我最喜欢的食物是什么？
我不知道你最喜欢的食物是什么。我们还没有讨论过这个话题。
```

这是有意设计的。每个新会话都是独立的，这意味着：
- Gemini 不会意外混淆不同任务的上下文
- 每次都有一个干净的起点
- 之前的对话不会拖慢速度

但当你*需要*连续性时，可以恢复之前的会话。

## 会话命令

### 命令对照表

**重要：** Gemini CLI 的命令标志与某些其他 CLI 工具不同。以下是清晰的对照：

| 操作 | Gemini CLI | 功能说明 |
|------|-----------|---------|
| 开始新会话 | `gemini` | 打开全新的对话 |
| 继续上一次会话 | `gemini --resume` 或 `gemini -r` | 从上次离开的地方继续 |
| 浏览历史会话 | `/resume`（在 CLI 内部） | 交互式会话选择器，支持搜索 |
| 列出所有会话 | `gemini --list-sessions` | 在终端显示会话历史 |
| 退出 | `Ctrl+D` 或输入 `exit` | 保存并退出当前会话 |

### `--resume` / `-r` — 继续上一次会话

```bash
gemini --resume
# 或更简短：
gemini -r
```

这会**继续**你上一次的会话。之前对话中的所有上下文都会恢复。当你中途离开后想继续时，使用这个命令。

**适用场景：**
- 你不小心关闭了终端
- 你休息了一会儿，想要继续
- 你需要跟进上次对话中的某些内容

### `/resume` — 浏览会话历史（在 CLI 内部）

在 Gemini CLI 内部，输入：
```
/resume
```

这会显示你所有过去会话的交互式列表。你可以：
- **搜索**会话以找到特定对话
- **选择**任何过去的会话来恢复它
- **删除**不再需要的会话

**适用场景：**
- 你想回到昨天或上周的某个对话
- 你记得讨论过某些内容但不确定是哪个会话
- 你想清理旧的会话

### `--list-sessions` — 查看会话历史

```bash
gemini --list-sessions
```

这会直接在终端打印你的会话列表，无需进入 CLI。适合快速查看会话历史概览。

## 动手练习 1：理解会话隔离

**目标：** 体验会话默认是如何隔离的。

**Part A — 在一个会话内：**

1. 启动 Gemini CLI：
   ```bash
   gemini
   ```
2. 告诉 Gemini：
   ```
   Let me tell you: my favorite food is cheese burger
   ```
3. 询问：
   ```
   What's my favorite food?
   ```
4. Gemini 应该正确回答："cheese burger"

**Part B — 跨会话：**

5. 退出 Gemini CLI（按 `Ctrl+D` 或输入 `exit`）
6. 开始新会话：
   ```bash
   gemini
   ```
7. 询问：
   ```
   What's my favorite food?
   ```
8. Gemini **不记得了** — 它没有上一个会话的上下文

**你学到了什么：** 每个新会话都从空白状态开始。上下文不会自动延续。

---

## 动手练习 2：使用 `--resume` 恢复会话

**目标：** 使用 `--resume` 来继续之前的会话。

**Part A — 创建一个带上下文的会话：**

1. 启动 Gemini CLI：
   ```bash
   gemini
   ```
2. 告诉 Gemini：
   ```
   Let me tell you my favorite programming language is Python
   ```
3. 退出（按 `Ctrl+D` 或输入 `exit`）

**Part B — 恢复并验证：**

4. 恢复上一次会话：
   ```bash
   gemini --resume
   ```
   （或更简短：`gemini -r`）
5. 询问：
   ```
   What programming language do I like?
   ```
6. Gemini **记住了** — 之前对话的上下文被恢复了！

**你学到了什么：** `--resume` 标志可以继续你上一次的会话，所有上下文完好无损。

---

## 动手练习 3：使用 `/resume` 浏览会话

**目标：** 使用交互式会话浏览器来查找和恢复过去的会话。

1. 启动 Gemini CLI：
   ```bash
   gemini
   ```
2. 输入命令：
   ```
   /resume
   ```
3. 在交互式选择器中浏览你过去的会话
4. 选择一个较早的会话（比如你提到最喜欢食物的那个会话）
5. 通过提问来验证该会话的上下文是否已恢复

**你学到了什么：** `/resume` 命令提供了一种可视化的方式来浏览所有会话、搜索内容，并选择任何一个继续。

## 快速参考

- **新会话：** `gemini`（默认）
- **继续上一次会话：** `gemini --resume` 或 `gemini -r`
- **浏览会话（CLI 内部）：** `/resume`
- **列出会话：** `gemini --list-sessions`
- **退出：** `Ctrl+D` 或输入 `exit`
- **会话存储：** 自动
- **上下文隔离：** 每个新会话默认从空白开始，除非你恢复

## 常见场景

### 场景 1："我昨天在调试一个问题"
你记得昨天在某个 bug 上取得了进展但没有完成。使用 `gemini --resume` 跳回那个对话，或者在 CLI 内使用 `/resume` 浏览会话历史找到正确的那个。

### 场景 2："我需要重新开始"
你来回讨论了很多，对话变得混乱了。只需退出并用 `gemini` 开始一个新会话。干净的状态，全新的开始。

### 场景 3："哪个会话里有那个讨论？"
你几天前讨论了一些重要的内容，但不确定是在哪个会话里。启动 Gemini CLI 并输入 `/resume` 来浏览你的会话历史。交互式浏览器让你可以搜索和预览会话。

## 导师寄语：组织你的思维

会话管理看似是一个小功能，但它反映了更深层的专业工作方式。

优秀的开发者不仅仅是写代码——他们还会组织自己的思维。他们知道什么时候应该从头开始，什么时候应该在之前的工作基础上继续。他们在有价值的时候保留上下文，在上下文造成干扰时清除它。

这是我的建议：

- **为每个独立的任务开始新会话。** 在修 bug？新会话。切换到新功能？新会话。这样可以保持对话专注，上下文清晰。
- **继续相同工作时恢复会话。** 如果你是在同一个任务上接着做，就恢复会话。你已经建立的上下文是有价值的。
- **不要害怕重新开始。** 如果对话变得混乱或偏离了方向，新会话往往比试图纠正方向更有效率。

我认识的最优秀的工程师都会有意识地使用他们的工具。他们不仅仅是使用功能——他们会思考*什么时候*和*为什么*使用它们。
