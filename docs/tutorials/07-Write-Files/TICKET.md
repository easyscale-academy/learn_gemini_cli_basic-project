# Directing AI Output Exactly Where You Want It

## Objective

Learn how to use absolute paths to control where Gemini CLI writes its output, and how to have the AI generate a "change notes" document alongside its work. This way, you get the task done efficiently, understand the reasoning behind it, and keep a complete record of every change.

## How-to Guide

1. Read the tutorial: [Gemini CLI Basics (Part 4): Directing AI Output Exactly Where You Want It](https://github.com/easyscale-academy/learn_gemini_cli_basic-project/tree/07-Write-Files/)
2. Work through the "Exercise 1" section hands-on
3. Complete every item in the Checklist below

## Checklist

- [ ] **Read the full tutorial** — Understand how to specify an output path and why changelogs are valuable
- [ ] **Complete the exercise** — Ask Gemini CLI to create a Python script and generate an accompanying explanation document at the same time
- [ ] **Verify the files were created** — Open the Explorer panel and confirm both files exist in the correct locations you specified
- [ ] **Review the explanation document** — Open the AI-generated doc and make sure it clearly describes what the code does and how it works
- [ ] **Build the habit** — Understand why every project should have a `docs/changes/` folder for tracking AI-driven modifications

## Grading Rubric

- **Output path usage:** Student used absolute paths in their prompt to direct Gemini CLI output to specific file locations
- **Script creation:** A Python script (`greet.py` or similar) exists at the student-specified path and runs correctly
- **Documentation creation:** An accompanying markdown file exists at a student-specified path, explaining what the script does, how to run it, and relevant concepts
- **Changelog understanding:** Student can explain why maintaining a `docs/changes/` folder is useful for AI-assisted development
