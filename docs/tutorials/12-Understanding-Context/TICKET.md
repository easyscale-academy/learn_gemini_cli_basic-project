# Learn Gemini CLI Basic 12 - Learn to Understand and Manage Context in Gemini CLI

## Objective

Learn what context is, why it matters, and how to manage it effectively through documentation strategies. Understand that even with Gemini's large context window (up to 1M tokens), good context management habits are essential.

Read the tutorial: [Understanding Context](https://github.com/easyscale-academy/learn_gemini_cli_basic-project/tree/12-Understanding-Context/)

## Actionable Items

1. Read the tutorial in `README.md`

2. **Complete the Exercise: Create Your First Documentation**

   **Part A: Have a Conversation (5-8 exchanges)**
   - Start Gemini CLI: `gemini`
   - Ask for food recommendations and have a casual conversation

   **Part B: Extract to Documentation**
   - Ask Gemini to create a concise markdown summary
   - Save as `docs/my-nutrition-plan.md`

   **Part C: Submit Your Work**
   - Verify document exists
   - Leave a comment with link and reflection

**Estimated time:** 20-30 minutes

## Key Concepts

- **Context** — Everything Gemini is currently processing
- **Context Window** — Up to ~1,000,000 tokens for Gemini Flash/Pro
- **Context Pressure** — Even with 1M tokens, long contexts can degrade quality
- **Documentation Strategy** — Convert conversations into reusable documents
- **Manual Compression** — Ask Gemini to condense important information
