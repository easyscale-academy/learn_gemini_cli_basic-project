# Learn Claude Code Basic 06 - Claude Code Basics (Part 3): Helping AI Understand Your Screen with Screenshots

## Objective

Learn how to take screenshots, upload them to your Codespace, and have Claude Code interpret what's on screen. When you hit an error or face a complex UI, a screenshot is faster and more accurate than trying to describe it in words.

## How-to Guide

1. Read the tutorial: [Claude Code Basics (Part 3): Helping AI Understand Your Screen with Screenshots](https://github.com/easyscale-academy/learn_gemini_cli_basic-project/tree/06-Read-Screenshots/)
2. Work through the hands-on exercise section in the document
3. Complete every item in the Checklist below

## Checklist

- [ ] **Read the full tutorial** — Understand the end-to-end workflow: take a screenshot → upload it → copy the file path → send it to the AI
- [ ] **Know your screenshot shortcut** — Make sure you can quickly capture your screen on your OS (Mac: `Cmd+Shift+4`, Windows: `Win+Shift+S`)
- [ ] **Practice uploading** — In the Codespace Explorer panel, right-click a folder and use the Upload option to upload your screenshot
- [ ] **Complete the exercise** — Take a screenshot of your current Codespace, upload it, and ask the AI to describe what it sees
- [ ] **Verify the result** — Confirm that the AI correctly interpreted the screenshot and returned an accurate description
