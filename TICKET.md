# Directing AI Output to the Right Place

## Objective

Learn how to use absolute paths to control where AI writes its output, and how to have the AI generate a "change notes" document alongside its work. This way, you get the task done efficiently, understand the reasoning behind it, and keep a complete record of every change.

## How-to Guide

1. Read the tutorial: [Claude Code Basics (Part 4): Directing AI Output to the Right Place](https://github.com/easyscale-academy/learn_gemini_cli_basic-project/tree/07-Write-Files/)
2. Work through the "Practice Exercise" section hands-on
3. Complete every item in the Checklist below

## Checklist

- [ ] **Read the full tutorial** — Understand how to specify an output path and why it's valuable to have the AI write change notes
- [ ] **Complete the practice exercise** — Ask the AI to create a simple Python script and generate an accompanying explanation document at the same time
- [ ] **Verify the files were created** — Open the Explorer panel in Codespace and confirm both files exist in the correct locations
- [ ] **Review the explanation document** — Open the AI-generated doc and make sure it clearly describes what the code does and how it works
- [ ] **Build the habit** — Understand why every project should have a `docs/changes/` folder for tracking AI-driven modifications
